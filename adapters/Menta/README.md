# AdMobMentaAdapter

See the full integration guide in [README.md](../README.md).

## Ad formats and class names

Set **Adapter class name** in the AdMob UI to:

| AdMob format | Class name |
| --- | --- |
| All formats (recommended) | `AdMobMentaAdapter` |
| App Open | `AdMobMentaSplashAdapter` |
| Banner | `AdMobMentaBannerAdapter` |
| Interstitial | `AdMobMentaInterstitialAdapter` |
| Rewarded / Rewarded Interstitial | `AdMobMentaRewardedAdapter` |
| Native | `AdMobMentaNativeAdapter` |
